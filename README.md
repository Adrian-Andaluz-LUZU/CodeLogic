##   Justificación y Propósito
* **Problema detectado:** Estudiantes de primeros semestres enfrentan dificultades para comprender conceptos abstractos de lógica, estructuras condicionales, iterativas y sintaxis en Java.
* **Usuario Objetivo:** Estudiantes universitarios de ingeniería/tecnología que inician su aprendizaje en programación.
* **Objetivo:** Proporcionar un entorno interactivo con lecciones estructuradas, ejemplos prácticos e interactivos para consolidar el aprendizaje paso a paso.

---

##  Tecnologías Utilizadas
* **Lenguaje Principal:** Java (JDK 21)
* **Framework Backend:** Spring Boot
* **Motor de Plantillas:** Thymeleaf
* **Frontend:** HTML5, CSS3, JavaScript
* **Gestor de Dependencias:** Maven
* **IDE Recomendado:** Visual Studio Code / IntelliJ IDEA
* **Control de Versiones:** Git & GitHub
